# WordWise
Kelime haznesi geliştirme, video tabanlı dinleme pratikleri ve oyunlaştırılmış bilgi yarışmaları sunan İngilizce öğrenme platformu.

## Ön yüz

Next.js + TypeScript uygulaması `frontend/` içindedir. Kurulum ve API bağlantısı için [frontend/README.md](frontend/README.md) dosyasına bak. Vitrin, giriş/kayıt ve canlı API bağlantılı admin önizlemesi içerir.
